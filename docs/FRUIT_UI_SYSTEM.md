# 水果挑选页面：已确认的设计与交互规则

2026-09-30。依据牛油果页面多轮实际反馈整理；牛油果已获用户认可，本轮应用于猕猴桃、石榴、柿子。

## 沟通结论

1. **图片负责教学。** 首屏果实要足够大，教学图必须看得见具体差别。需要比较时同时展示两个状态，配清楚的判断标签，而不是只写“检查一下”。
2. **检查后知道如何选。** 说明检查方式、理想状态、需要避开的迹象；分清外观线索、手感线索与品种规则。相同照片无法传达硬度时，提供显眼的 Check firmness 框和 Resistance 结果。
3. **一屏一个阅读单元。** 图片尺寸结合视口高度，减少过大标题、内边距和无效留白。双语与小屏内容允许自然增长，不裁字、不锁滚动。
4. **保持自然的图片背景。** 图片与页面背景融合，悬停、按压、反馈状态都不能突然出现白色矩形；不缩放整个透明选项父层。
5. **减少套框。** 单一互动区外框、轻量选择按钮、分隔线与文字反馈。保留有实际用途的检查标注，避免大空框挤压果实。
6. **答题前中立，答题后讲清楚。** 两个选项同等呈现；选择后显示两个选项各自的结论和理由。正确、错误都必须点击 Got it 才继续，末题亦然。
7. **原生滚动与明确控制。** 不截获滚轮，不将互动区做成嵌套滚动面板；保留键盘操作、焦点恢复、Restart 和减少动态效果支持。
8. **颜色对应水果。** 共享排版与交互规则，每种水果拥有自己的页面、文字、按钮、描边和浅色背景。绿色勾、红色叉是答题状态色，与水果主题独立。
9. **证据符合购买场景。** 购买前只能依靠完整果实的外观、标签／卖家确认、重量和轻触手感；不能用切面、果肉或品尝结果让读者挑选未购买的水果。静态图片不能证明软硬或重量，需提供检查结果或明确的手感描述。分清“适合买回家等待成熟”和“适合马上吃”，不能把尚未软熟直接标成损坏。

## 三页实施

| 页面 | 配色 | 教学重点 |
| --- | --- | --- |
| 猕猴桃 | 果肉绿 `#526D22`、暖棕文字、米白 `#FBFAF2` | 手掌轻压、均匀软硬、饱满与皱缩对比；硬度题使用可点击检查 |
| 石榴 | 籽红 `#9A3048`、深酒红、浅粉 `#FFF8F7` | 同等大小比较重量、轻微棱角与圆形、完整果皮与裂伤对比 |
| 柿子 | 柿橙 `#A95116`、深棕、奶油底 `#FFFAF2` | Fuyu 与 Hachiya 并排识别、不同软硬标准、完整与损伤对比 |

## 本轮实现边界

- 沿用现有正式水果照片，以 HTML 标签、说明和对比排版增强教学。图片题使用原有受控对比素材；文字题保留可读卡片，不制造无法表达手感的伪图片差异。
- 品种、答案、营养数据与来源维持原有内容依据；新增说明归纳现有正文及学习点。
- 所有三页开启共享紧凑版式；主题使用独立变量，牛油果保留原有颜色作为默认值。
